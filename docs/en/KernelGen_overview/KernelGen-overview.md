# KernelGen Overview

**KernelGen** is designed to generate, optimize, and specialize Kernels across diverse hardware platforms. After connecting to KernelGen Operator Development MCP Toolkit, you can either accomplish these tasks using the toolkit alone or combine it with first- and third-party skills. Users can invoke KernelGen Operator Development MCP Toolkit and these skills in VSCode (and GitHub Copilot), Claude Code, or OpenClaw.
