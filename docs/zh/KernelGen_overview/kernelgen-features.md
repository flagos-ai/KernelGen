# 功能特性

KernelGen Web 支持通过以下方式之一生成、优化和特化 Kernel：

- KernelGen Web 平台
- KernelGen 算子开发 MCP 工具集及其 MCP 工具：所有 MCP 工具均集成于 MCP 工具集中。
- KernelGen 算子开发 MCP 工具集与 KernelGen Skills：所有 KernelGen Skills 均打包于 kernelgen-flagos skill 中。用户可通过调用该 skill 来调用其中的子技能。
