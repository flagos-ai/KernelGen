# KernelGen 概述

**KernelGen** 旨在跨多种硬件平台生成、优化和特化 Kernel。连接 KernelGen 算子开发 MCP 工具集后，您可以单独使用该工具集完成上述任务，也可以将其与第一方和第三方 Skills 结合使用。用户可在 VSCode（及 GitHub Copilot）、Claude Code 或 OpenClaw 中调用 KernelGen 算子开发 MCP 工具集和这些Skills。
